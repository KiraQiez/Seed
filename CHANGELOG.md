# Changelog

## [0.2.0] — 2026-11-28

- Add guided setup with `seed init --interactive` to choose a schema, tables, and row counts.
- Group terminal help by task and show clearer plan, preview, validation, apply, and export results.
- Add a beginner guide with a disposable PostgreSQL example and custom generation rules.

## [0.1.0] — 2026-11-28

- Inspect PostgreSQL schemas and build dependency-ordered generation plans.
- Preview deterministic samples and validate a full dataset offline.
- Apply synthetic rows to an explicitly configured development or test target in one transaction.
- Export related data as SQL, CSV, or JSON with a completion manifest.
