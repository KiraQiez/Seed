# Seed

Generate realistic, related test data for PostgreSQL development and test databases. Seed inspects your schema, plans rows in dependency order, and lets you preview, apply, or export the dataset as SQL, CSV, or JSON.

```sh
uv tool install seed-dev-db
seed --help
```

Seed requires Python 3.12 or newer. See the [project README](https://github.com/KiraQiez/Seed#readme) for configuration and the [PostgreSQL support matrix](https://github.com/KiraQiez/Seed/blob/main/docs/DATA_MODEL.md#postgresql-support) for supported schema features.
