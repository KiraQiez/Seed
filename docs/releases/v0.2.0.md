# Seed v0.2.0

Start with `seed init --interactive` to choose your schema, tables, and row counts. Help groups commands by task, and terminal results make it easier to read plan counts, preview rows, validation statuses, and write outcomes.

The [beginner guide](https://github.com/KiraQiez/Seed/blob/v0.2.0/Guide.md) walks through generating 10 fake customers in PostgreSQL, including how to set custom column rules, preview rows, export files, and safely apply the results.

```sh
uv tool upgrade seed-dev-db
seed --version
seed --help
```

The existing configuration and JSON response formats still work. Guided setup is optional, and applying rows still requires a matching development or test target. [Command reference](https://github.com/KiraQiez/Seed/blob/v0.2.0/docs/CLI_SPEC.md)
