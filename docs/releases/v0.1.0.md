# Seed v0.1.0

Seed’s first release generates related synthetic data for PostgreSQL development and test databases. It supports inspection, planning, preview, full offline validation, guarded apply, and SQL, CSV, and JSON export.

```sh
uv tool install seed-dev-db==0.1.0
seed --version
```

Use Python 3.12 or newer. Seed was tested on PostgreSQL 15–19. Apply requires a matching, explicitly configured target. SQL and CSV imports use a matching empty development or test schema and require sequence reconciliation for explicit identities. See the [command reference](https://github.com/KiraQiez/Seed/blob/v0.1.0/docs/CLI_SPEC.md) and [supported schema features](https://github.com/KiraQiez/Seed/blob/v0.1.0/docs/DATA_MODEL.md#postgresql-support).
